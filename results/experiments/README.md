# Experiment Results (MPI vs Master-Slave)

This directory stores reproducible experiment sessions generated by:

```bash
./cluster-config/run-experiments.sh
```

Each run creates:

- `results/experiments/<session>/results.csv`
- `results/experiments/<session>/summary.csv`
- `results/experiments/<session>/logs/*.log` (optional)

## Pairing Rule

Comparisons are done with equivalent compute power:

- `MPI 2` nodes  <-> `MS 3` nodes
- `MPI 4` nodes  <-> `MS 5` nodes
- `MPI 8` nodes  <-> `MS 9` nodes

The extra master-slave node is rank 0 (master), while sinks execute tasks.

## Default Matrix

- MPI nodes: `2, 4, 8`
- Master-slave nodes: `3, 5, 9`
- Bodies: `2^19`, `2^20` (via `--exp 18`, `--exp 19`)
- Parts per case: `gpu_lanes`, `4*gpu_lanes`
- Repetitions per case: `1 warmup + 2 timed`

Expected rows for full run (`--mode both`):

- MPI: `3 * 2 * 2 * 3 = 36`
- MS: `3 * 2 * 2 * 3 = 36`
- Total: `72`

## CSV Schema

`results.csv` columns:

`timestamp,mode,nodes,np,paired_nodes,exp,n_bodies,parts,gpu_lanes,rep_kind,rep_idx,time_us,run_ok,notes`

- `time_us`: runtime printed by nbody (microseconds)
- `rep_kind`: `warmup` or `timed`
- `run_ok`: `1` for successful run with parsed time, else `0`

`summary.csv` columns:

`mode,nodes,paired_nodes,exp,n_bodies,parts,gpu_lanes,samples,mean_us,min_us,max_us,stddev_us`

- Uses only rows where `rep_kind=timed` and `run_ok=1`
- Grouped by `mode,nodes,exp,parts` (with corresponding paired metadata)

## Usage

1. Prepare cluster IP state with `cluster-config/cluster-mpi.sh set-ips ...`.
2. Optionally create `cluster-config/experiments.env` from `experiments.env.example`.
3. Run:

```bash
./cluster-config/run-experiments.sh --mode both
```

Examples:

```bash
./cluster-config/run-experiments.sh --mode mpi
./cluster-config/run-experiments.sh --mode ms --session ms-run-a
./cluster-config/run-experiments.sh --mode both --no-sync
```

## Notes

- The runner does not provision cloud resources.
- It uses existing `cluster-config/cluster-mpi.sh` commands to sync/build/run.
- Intended benchmark settings are non-debug and no FXT tracing.
